## The library

The engine is the `core` library, and its interface is `latex.hpp`, in the namespace `latex`. Link `core` from the mLaTeX build, as the `mlatex` program and every test do.

***

## A session

```cpp
#include "latex.hpp"

#include <iostream>

int main(int, char* arguments[]) {
    latex::Session session(latex::locate(arguments[0]));

    session.set("customer", "Acme Corporation");
    session.define({.name = "balance", .arity = 1, .handler = [](auto values) {
        return values[0] == "A-1042" ? std::string("12.50") : std::string("0.00");
    }});
    session.provide("letterhead/main.mtex", "\\newcommand{\\letterhead}{\\textbf{Acme}}");

    const bool clean = session.typeset(R"(\documentclass{article}
\usepackage{letterhead}
\begin{document}
\letterhead\par
Billed to \variable{customer}. Balance: \$\balance{A-1042}.
\end{document})");

    if (!clean) std::cerr << session.error;
    // session.pdf holds the PDF's bytes; session.pages each page's text.
}
```

### Session(assets)

A session over an assets folder: the fonts, and the hyphenation patterns not built in. See [Finding the assets](#finding-the-assets).

### set and unset

`set(name, value)` gives a value the document reads with `\variable{name}`, and `unset(name)` takes it back.

### define and forget

`define(command)` gives a command the program implements, as a `latex::Command`:

| Field     | What it is                                                                |
| --------- | ------------------------------------------------------------------------- |
| `name`    | The command's name, with or without its backslash.                        |
| `arity`   | How many brace groups it reads, up to nine.                               |
| `handler` | Called with the arguments' text; returns the text the command stands for. |

`forget(name)` takes a command back.

### provide and withdraw

`provide(name, bytes)` hands in a file from memory, under the name the document uses, and `withdraw(name)` takes it back.

### typeset

`typeset(document)` makes a PDF and returns `true` when nothing was reported.

### pdf, error and pages

| Member  | What it is                                      |
| ------- | ----------------------------------------------- |
| `pdf`   | The last PDF made, or empty when none could be. |
| `error` | What went wrong last time, one error per line.  |
| `pages` | Each page's text, for checking or indexing.     |

### host

`host` is everything the next document will be handed: `variables`, `commands`, `files`, `directories` and `offline`. The operations above change it, and it can be changed directly too:

```cpp
session.host.directories.push_back("styles");   // read packages and inputs from here too
session.host.offline = true;                     // refuse every network request
```

## Finding the assets

### latex::locate

`latex::locate(binary)` walks up from a path to the first folder holding `assets/fonts`, the way the `mlatex` program finds its own fonts. Pass it your program's path, or name the assets folder yourself.

***

## Without a session

For one document at a time, two functions do the same work:

```cpp
// A document on disk into a PDF on disk, as the command line does.
bool clean = latex::compose(assets, "paper.tex", "paper.pdf", host, &std::cout, std::cerr);

// A document in memory into a PDF in memory, quietly.
std::string pdf;
bool clean = latex::typeset(assets, document, pdf, host, std::cerr);
```

### latex::compose

`compose` reads a document from disk and writes its PDF to disk. It takes where its report goes (`nullptr` for none) and where errors go; an empty destination makes a draft, which writes no PDF.

### latex::typeset

`typeset` makes a PDF from a document in memory into a string, reporting only errors.

Both take an optional last argument that receives each page's text.
