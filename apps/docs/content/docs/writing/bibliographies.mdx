---
title: Bibliographies
description: Citing from .bib files with BibTeX's styles, natbib and biblatex, with no separate BibTeX step.
---

mLaTeX reads `.bib` files itself. There is no BibTeX or Biber to run and no `.bbl` to keep up to date: cite, name the file, and compile once.

## With BibTeX's commands

```latex title="paper.tex"
\documentclass{article}
\begin{document}
Literate programming~\cite{knuth84} changed how programs are written.

\bibliographystyle{plain}
\bibliography{refs}
\end{document}
```

```bibtex title="refs.bib"
@article{knuth84,
  author  = {Donald E. Knuth},
  title   = {Literate Programming},
  journal = {The Computer Journal},
  year    = {1984},
  volume  = {27},
  pages   = {97--111}
}
```

`\cite{a,b}` cites several entries, `\cite[p.~5]{knuth84}` adds a note, and `\nocite{key}` lists an entry without citing it; `\nocite{*}` lists every entry in the file. Entries are chosen, sorted, labelled and set in the style named.

### Styles

| Style                                                | Cites as                 | Sorted             |
| ---------------------------------------------------- | ------------------------ | ------------------ |
| `plain`, `abbrv`                                     | `[1]`                    | By author          |
| `unsrt`, `ieeetr`, `IEEEtran`                        | `[1]`                    | In the order cited |
| `alpha`                                              | `[Knu84]`                | By author          |
| `plainnat`, `abbrvnat`, `apalike`, `agsm`, `chicago` | Knuth (1984) with natbib | By author          |
| `ACM`, `splncs`, `siam`, `elsarticle`, `ams`         | Each publisher's own way | As the style does  |
| `apsrev`, the AIP's styles                           | `[1]`, initials first    | In the order cited |

A style mLaTeX does not know is set as `plain`.

## By author and year: natbib

```latex
\usepackage{natbib}
\citet{knuth84} showed it \citep{lamport94}.   % Knuth (1984) showed it (Lamport, 1994).
\citep[see][p.~5]{knuth84}                      % (see Knuth, 1984, p. 5)
\bibliographystyle{plainnat}
\bibliography{refs}
```

`\citet`, `\citep`, `\citeauthor`, `\citeyear`, `\citealt`, `\citealp` and `\citenum`, their capitalised forms, and the `numbers` option, which cites every entry by number.

## biblatex

```latex
\usepackage[style=authoryear]{biblatex}
\addbibresource{refs.bib}
\begin{document}
\textcite{knuth84} and \parencite{lamport94}.
\printbibliography
\end{document}
```

`\textcite`, `\parencite`, `\autocite`, `\smartcite` and `\supercite` work, and each style is set as the BibTeX style nearest it:

| biblatex style                                             | Set as                      |
| ---------------------------------------------------------- | --------------------------- |
| `authoryear`, `apa`, `chicago`, `harvard`, `authortitle`   | Author and year             |
| `ieee`                                                     | IEEE's style                |
| `alphabetic`                                               | `[Knu84]` labels            |
| `nature`, `science`, the physics styles, or `sorting=none` | Numbered in the order cited |
| any other                                                  | Numbered, sorted by author  |

`\printbibliography` reads `heading=none`, `heading=bibintoc` and `title=`. A report's or a book's bibliography is a chapter, as those classes have it.

## Where the entries come from

* **A `.bib` file** beside the document, in a folder given with `-I`, or handed in by a program.
* **Imported with `\input`.** `\input{refs.bib}` makes a `.bib` file a source of the bibliography, as `\addbibresource` does, and `\bibliography{}` or `\printbibliography` then sets what it holds.
* **Carried in the document.** A `filecontents` block holding the entries is kept for the run, so the document is a single file.
* **A ready-made `.bbl`.** A paper sent to a journal or the arXiv often carries the `.bbl` file BibTeX wrote instead of its `.bib`. When none of the files `\bibliography` names can be read, the document's own `.bbl` is set in its place.
* **Written by hand.** A `thebibliography` block with `\bibitem` entries works as in LaTeX, natbib's `\bibitem[Knuth(1984)]{knuth}` included.

The `.bib` reader understands `@string` abbreviations, `#` concatenation, month names, `@comment`, and `@preamble`, whose text is placed ahead of the list so that commands the entries use are defined.

## Looking a bibliography over

Give a `.bib` file as the document to set every entry it holds, cited or not, as a list:

```bash
mlatex refs.bib
```

## Mistakes

A citation with no entry is a warning, ``Citation `key' undefined``, and prints `?`. A `.bib` file that cannot be read is an error that names it.
