## Including a picture

```latex
\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.8\linewidth]{plot}
  \caption{Error against mesh width.}
  \label{fig:plot}
\end{figure}
```

`\includegraphics` is part of the engine, so `graphicx` and `graphics` are accepted and need nothing loaded. It reads `width`, `height`, `scale`, `angle` and `keepaspectratio`. A picture named without an extension is looked for as `.png`, `.jpg`, `.jpeg`, `.webp`, `.pdf`, `.eps`, `.ps` and `.svg`, in the document's folder, the folders `\graphicspath` lists, and the folders given with `-I`.

## Formats

| Format          | How it is used                                                                                     |
| --------------- | -------------------------------------------------------------------------------------------------- |
| PNG             | Decoded and compressed into the PDF                                                                |
| JPEG            | Embedded exactly as it came, never decoded or recompressed                                         |
| WebP            | Decoded and compressed into the PDF                                                                |
| PDF             | The page itself, fonts and vectors intact; `page=`, `trim=`, `viewport=` and `clip` are read       |
| EPS             | Its PostScript is run and drawn as vectors                                                         |
| SVG             | Its shapes, paths, transforms, styles and text are drawn as vectors; `\includesvg{name}` works too |
| `.tikz`, `.pgf` | Read as the TikZ picture they contain                                                              |

A picture's natural size follows the resolution in its file, or 72 dpi when it gives none, as in pdfTeX. A form mLaTeX cannot draw keeps its place as an empty frame of the right size, with a warning.

<Callout type="info">
  Text inside an EPS or SVG picture is set in the nearest of PDF's standard fonts rather than the font the file embeds, and an SVG gradient is drawn in its first colour.
</Callout>

## Pictures from the web

`\includegraphics{https://example.com/chart.png}` fetches the picture when the document is set. Run with `--offline` to refuse every network request instead; see [Security](/docs/security).

## Placeholders

`mwe`'s `example-image`, `example-image-a` and their kin are drawn as framed boxes of the right size with their names in them, so a layout can be checked before its pictures exist.

## Floats

Figures and tables float to where LaTeX's own algorithm puts them, within the placement you allow:

| Option | Meaning                                                 |
| ------ | ------------------------------------------------------- |
| `h`    | Here, where it is written, if it fits                   |
| `t`    | At the top of a page                                    |
| `b`    | At the bottom of a page                                 |
| `p`    | On a page of floats                                     |
| `!`    | Ignore the limits on how much of a page floats may take |
| `H`    | Exactly here; needs the `float` package                 |

`\topfraction`, `\bottomfraction`, `\textfraction`, `\floatpagefraction`, `topnumber` and the rest are respected, figures and tables each keep their order, and `figure*` and `table*` span both columns of a two-column page. `\clearpage`, or placeins' `\FloatBarrier`, sets everything still waiting.

`wrapfig`'s `wrapfigure`, `rotating`'s `sidewaysfigure` and `sidecap`'s `SCfigure` are accepted and set as floats of the engine's own.

## Captions

`\caption` and `\label` work as in LaTeX, and the `caption` package's `font`, `labelfont` and `labelsep` options are read:

```latex
\usepackage[font=small, labelfont=bf, labelsep=period]{caption}
```

`\captionof{figure}{...}` captions something outside a float.

## Figures made of parts

```latex
\usepackage{subcaption}

\begin{figure}[htbp]
  \begin{subfigure}{0.48\linewidth}
    \includegraphics[width=\linewidth]{coarse}
    \caption{Coarse mesh}
  \end{subfigure}
  \hfill
  \begin{subfigure}{0.48\linewidth}
    \includegraphics[width=\linewidth]{fine}
    \caption{Fine mesh}
  \end{subfigure}
  \caption{Two meshes.}
\end{figure}
```

Each part is lettered, and a reference to one prints as `1a`. `subfig`'s `\subfloat` works the same way.

## Floats of your own

```latex
\usepackage{newfloat}
\DeclareFloatingEnvironment[name=Scheme]{scheme}
```

`newfloat`'s `\DeclareFloatingEnvironment` and `float`'s `\newfloat` make a new kind of float with its own counter and caption name. `algorithm` is one already, for pseudocode.
