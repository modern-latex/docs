## Loading

```latex
\usepackage{tcolorbox}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\newtcbox`, `\newtcolorbox`, `\tcbox`, `\tcbset`, `\tcbuselibrary`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="tcolorbox.tex" preview
\documentclass{article}
\usepackage[most]{tcolorbox}
\begin{document}
\tcbset{colback=blue!5}
\begin{tcolorbox}[title=A box, colframe=blue!50]
Inside a coloured box.
\end{tcolorbox}
\newtcolorbox{note}[1][]{colback=yellow!10, title=Note, #1}
\begin{note}A note.\end{note}
\tcbox{inline}
\end{document}
```

## Limits

<Callout type="warn">
  Its libraries and inline boxes are ignored.
</Callout>
