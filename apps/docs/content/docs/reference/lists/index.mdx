19 packages. Each page says how mLaTeX supports one, lists the commands it gives, and shows a document that uses it, taken from mLaTeX's own tests so that it compiles as written.

| Name                                                   | What it does                                                                                                                                 |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| [`adjustbox`](/docs/reference/lists/adjustbox)         | Adjusted boxes                                                                                                                               |
| [`awesomebox`](/docs/reference/lists/awesomebox)       | Admonitions                                                                                                                                  |
| [`bclogo`](/docs/reference/lists/bclogo)               | Boxes with logos                                                                                                                             |
| [`boxedminipage`](/docs/reference/lists/boxedminipage) | A minipage in a frame                                                                                                                        |
| [`dirtree`](/docs/reference/lists/dirtree)             | Directory trees                                                                                                                              |
| [`enumerate`](/docs/reference/lists/enumerate)         | List labels by example                                                                                                                       |
| [`enumitem`](/docs/reference/lists/enumitem)           | Control over lists' labels and spacing                                                                                                       |
| [`exsheets`](/docs/reference/lists/exsheets)           | Questions and solutions                                                                                                                      |
| [`fancybox`](/docs/reference/lists/fancybox)           | Boxes framed with a shadow, a double line or rounded corners, each drawn here as a plain frame                                               |
| [`framed`](/docs/reference/lists/framed)               | Framed, shaded and leftbar blocks, mLaTeX's own                                                                                              |
| [`mdframed`](/docs/reference/lists/mdframed)           | A framed block that may run over pages, mLaTeX's own, in the colors its options name                                                         |
| [`mdwlist`](/docs/reference/lists/mdwlist)             | Compact lists                                                                                                                                |
| [`multienum`](/docs/reference/lists/multienum)         | Several items to a line                                                                                                                      |

| [`tcolorbox`](/docs/reference/lists/tcolorbox)         | A colored box with a title, mLaTeX's own, and a box of a name of the document's, `\newtcolorbox`, with the options `\tcbset` gives every box |
| [`trimclip`](/docs/reference/lists/trimclip)           | Boxes trimmed                                                                                                                                |
