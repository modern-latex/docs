---

## Loading

```latex
\usepackage{enumitem}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\alph`, `\newlist`, `\SetLabelAlign`, `\setlist`, `\setlistdepth`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="enumitem.tex"
\documentclass{article}
\usepackage[inline]{enumitem}
\begin{document}
\setlist[itemize]{noitemsep}
\begin{enumerate}[label=(\alph*), start=3]
\item first
\item second
\end{enumerate}
\begin{itemize}[leftmargin=*]
\item a
\end{itemize}
\begin{description}[style=nextline]
\item[Term] its description
\end{description}
\newlist{steps}{enumerate}{1}
\setlist[steps]{label=Step \arabic*.}
\begin{enumerate*}[label=(\roman*)]
\item one \item two
\end{enumerate*}
\end{document}
```
