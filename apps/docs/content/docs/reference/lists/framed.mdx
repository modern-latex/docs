## Loading

```latex
\usepackage{framed}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\definecolor`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="framed.tex" preview
\documentclass{article}
\usepackage{framed}
\usepackage{xcolor}\definecolor{shadecolor}{gray}{0.9}
\begin{document}
\begin{framed}
A framed paragraph.
\end{framed}
\begin{shaded}
A shaded paragraph.
\end{shaded}
\begin{leftbar}
A bar at the left.
\end{leftbar}
\end{document}
```
