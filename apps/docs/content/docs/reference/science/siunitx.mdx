## Loading

```latex
\usepackage{siunitx}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="siunitx.tex" preview
\documentclass{article}
\usepackage{siunitx}
\usepackage{booktabs}
\begin{document}
\sisetup{per-mode=symbol}
\SI{9.81}{\metre\per\second\squared}, \qty{3}{\kilo\gram}, \si{\joule}, \num{12345.678}, \num{1e-3}, \ang{30}, \SIrange{1}{5}{\milli\metre}, \numlist{1;2;3}, \unit{\newton\metre}, \qtyrange{1}{2}{\hertz}.
\begin{tabular}{S[table-format=2.2]}
\toprule
{Value} \\ \midrule 1.5 \\ 12.25 \\ \bottomrule
\end{tabular}
\end{document}
```
