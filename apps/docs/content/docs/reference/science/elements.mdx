## Loading

```latex
\usepackage{elements}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\atomicnumber`, `\Elementname`, `\elementname`, `\elementsymbol`, `\setatomsep`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="elements.tex"
\documentclass{article}
\usepackage{elements}
\begin{document}
\elementsymbol{6} is \elementname{6}; \elementsymbol{79} is \elementname{79}; carbon is number \atomicnumber{C}.
\end{document}
```
