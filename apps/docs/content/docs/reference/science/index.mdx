title: Science and Units
description: Units, numbers, chemistry and physics notation.
---

16 packages. Each page says how mLaTeX supports one, lists the commands it gives, and shows a document that uses it, taken from mLaTeX's own tests so that it compiles as written.

| Name                                                   | What it does                                                                                                              |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| [`chemfig`](/docs/reference/science/chemfig)           | Structural formulas                                                                                                       |
| [`chemformula`](/docs/reference/science/chemformula)   | Chemical formulas                                                                                                         |
| [`chemmacros`](/docs/reference/science/chemmacros)     | Chemistry macros                                                                                                          |
| [`elements`](/docs/reference/science/elements)         | The chemical elements by atomic number: symbols and names                                                                 |
| [`eurosym`](/docs/reference/science/eurosym)           | The euro sign, and an amount written with it                                                                              |
| [`gensymb`](/docs/reference/science/gensymb)           | The units' signs, the same in text and in formulas — a text face's own sign in the text, the maths face's in a formula    |
| [`hepnames`](/docs/reference/science/hepnames)         | Particle names                                                                                                            |
| [`hepparticles`](/docs/reference/science/hepparticles) | Particles                                                                                                                 |
| [`hepunits`](/docs/reference/science/hepunits)         | Particle physics units                                                                                                    |
| [`mhchem`](/docs/reference/science/mhchem)             | Chemical formulas and equations: `\ce{2H2 + O2 -> 2H2O}`                                                                  |
| [`sistyle`](/docs/reference/science/sistyle)           | SI style                                                                                                                  |
| [`SIunits`](/docs/reference/science/siunits)           | Values and units, the units as commands of their own — the package siunitx replaced, still found in older documents       |
| [`siunitx`](/docs/reference/science/siunitx)           | Numbers and quantities set the way siunitx sets them, with its defaults, so a document written for it reads the same here |
| [`slashed`](/docs/reference/science/slashed)           | Feynman's slash                                                                                                           |
| [`units`](/docs/reference/science/units)               | A value and its unit, apart by a thin space, and a unit as a fraction                                                     |
| [`unitsdef`](/docs/reference/science/unitsdef)         | Units defined                                                                                                             |
