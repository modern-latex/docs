## Loading

```latex
\usepackage{sistyle}
```

Loads [`siunitx`](/docs/reference/science/siunitx) under this name, so a document asking for either gets the same.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="sistyle.tex"
\documentclass{article}
\usepackage{sistyle}
\begin{document}
\num{12345} \SI{5}{m}
\end{document}
```
