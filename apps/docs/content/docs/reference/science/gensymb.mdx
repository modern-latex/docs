## Loading

```latex
\usepackage{gensymb}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\celsius`, `\degree`, `\micro`, `\ohm`, `\perthousand`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="gensymb.tex"
\documentclass{article}
\usepackage{gensymb}
\begin{document}
20\,\degree C, 5\,\celsius, 10\,\ohm, 3\,\micro m, 5\,\perthousand; $90\degree$.
\end{document}
```
