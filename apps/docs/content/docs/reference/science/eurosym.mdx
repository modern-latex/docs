title: eurosym
description: 'The euro sign, and an amount written with it.'
---

## Loading

```latex
\usepackage{eurosym}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\EUR`, `\euro`, `\officialeuro`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="eurosym.tex"
\documentclass{article}
\usepackage{eurosym}
\begin{document}
\euro{} 100 and \EUR{250}.
\end{document}
```
