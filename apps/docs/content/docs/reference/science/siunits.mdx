## Loading

```latex
\usepackage{SIunits}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\ampere`, `\candela`, `\celsius`, `\centi`, `\coulomb`, `\cubed`, `\degree`, `\farad`, `\giga`, `\gram`, `\henry`, `\hertz`, `\joule`, `\kelvin`, `\kilo`, `\kilogram`, `\litre`, `\mega`, `\meter`, `\metre`, `\micro`, `\milli`, `\mole`, `\nano`, `\newton`, `\ohm`, `\pascal`, `\per`, `\pico`, `\reciprocal`, `\second`, `\squared`, `\tesla`, `\unit`, `\unitfrac`, `\usk`, `\volt`, `\watt`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="SIunits.tex" preview
\documentclass{article}
\usepackage{SIunits}
\begin{document}
\unit{5}{\metre}
\end{document}
```
