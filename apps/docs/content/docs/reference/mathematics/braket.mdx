## Loading

```latex
\usepackage{braket}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\Bra`, `\bra`, `\Braket`, `\braket`, `\Ket`, `\ket`, `\phi`, `\psi`, `\Set`, `\set`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="braket.tex" preview
\documentclass{article}
\usepackage{braket}
\begin{document}
$\bra{\psi} \quad \ket{\phi} \quad \braket{\psi|\phi} \quad \Braket{\psi|A|\phi} \quad \set{x | x > 0}$
\end{document}
```
