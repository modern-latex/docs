## Loading

```latex
\usepackage{amsopn}
```

Loads [`amsmath`](/docs/reference/mathematics/amsmath) under this name, so a document asking for either gets the same.

## Commands

`\Ker`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="amsopn.tex" preview
\documentclass{article}
\usepackage{amsopn}
\begin{document}
\DeclareMathOperator{\Ker}{Ker}$\Ker f \operatorname{tr} A$
\end{document}
```
