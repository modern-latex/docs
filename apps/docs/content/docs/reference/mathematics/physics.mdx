## Loading

```latex
\usepackage{physics}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\abs`, `\Arg`, `\comm`, `\curl`, `\dv`, `\grad`, `\Im`, `\ip`, `\laplacian`, `\norm`, `\order`, `\pd`, `\pdv`, `\phi`, `\Re`, `\tr`, `\vb`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="physics.tex" preview
\documentclass{article}
\usepackage{physics}
\begin{document}
$\abs{x} \quad \norm{v} \quad \dv{f}{x} \quad \pdv{f}{x}{y} \quad \qty(\frac{a}{b}) \quad \bra{a}\ket{b} \quad \expval{H} \quad \tr{A} \quad \grad{f} \quad \curl{F} \quad \laplacian{\phi} \quad \order{x^2} \quad \eval{x}_0^1 \quad \vb{x} \quad \comm{A}{B}$
\end{document}
```
