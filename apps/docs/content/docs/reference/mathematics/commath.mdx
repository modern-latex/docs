description: 'The notations of calculus and analysis written short.'
---

## Loading

```latex
\usepackage{commath}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\abs`, `\cbr`, `\del`, `\Dif`, `\dif`, `\enVert`, `\envert`, `\eval`, `\fullfunction`, `\intcc`, `\intco`, `\intoc`, `\intoo`, `\md`, `\norm`, `\od`, `\pbr`, `\pd`, `\sbr`, `\set`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="commath.tex" preview
\documentclass{article}
\usepackage{commath}
\begin{document}
$\dif x \quad \od{y}{x} \quad \pd{f}{x} \quad \abs{x} \quad \norm{v} \quad \set{1,2}$
\end{document}
```
