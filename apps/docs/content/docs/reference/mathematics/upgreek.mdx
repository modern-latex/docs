---
title: upgreek
description: 'Upright Greek letters in a formula.'
---

## Loading

```latex
\usepackage{upgreek}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\upalpha`, `\upbeta`, `\upchi`, `\Updelta`, `\updelta`, `\upepsilon`, `\upeta`, `\Upgamma`, `\upgamma`, `\upiota`, `\upkappa`, `\Uplambda`, `\uplambda`, `\upmu`, `\upnu`, `\Upomega`, `\upomega`, `\Upphi`, `\upphi`, `\Uppi`, `\uppi`, `\Uppsi`, `\uppsi`, `\uprho`, `\Upsigma`, `\upsigma`, `\uptau`, `\Uptheta`, `\uptheta`, `\Upupsilon`, `\upupsilon`, `\Upxi`, `\upxi`, `\upzeta`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="upgreek.tex"
\documentclass{article}
\usepackage{upgreek}
\begin{document}
$\upalpha \upbeta \upgamma \Updelta \upmu \uppi$
\end{document}
```
