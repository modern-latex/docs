## Loading

```latex
\usepackage{physics2}
```

Loads [`physics`](/docs/reference/mathematics/physics) under this name, so a document asking for either gets the same.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="physics2.tex"
\documentclass{article}
\usepackage{physics2}
\begin{document}
$\abs{x} \quad \norm{y}$
\end{document}
```
