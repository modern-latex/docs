---
title: nicefrac
description: 'A fraction written small, its numerator raised and denominator lowered either side of a slash.'
---

## Loading

```latex
\usepackage{nicefrac}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\nicefrac`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="nicefrac.tex"
\documentclass{article}
\usepackage{nicefrac}
\begin{document}
$\nicefrac{1}{2}$ and \nicefrac{3}{4} of it.
\end{document}
```
