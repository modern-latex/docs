## Loading

```latex
\usepackage{ntheorem}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\newtheorem`, `\qedsymbol`, `\theorembodyfont`, `\theoremclass`, `\theoremheaderfont`, `\theoremindent`, `\theoremnumbering`, `\theorempostwork`, `\theoremprework`, `\theoremseparator`, `\theoremsymbol`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="ntheorem.tex" preview
\documentclass{article}
\usepackage{ntheorem}
\begin{document}
\theoremstyle{break}
\newtheorem{theorem}{Theorem}
\begin{theorem}A theorem, its body under its head.\end{theorem}
\end{document}
```
