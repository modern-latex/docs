## Loading

```latex
\usepackage{IEEEtrantools}
```

Loads [`amsmath`](/docs/reference/mathematics/amsmath) under this name, so a document asking for either gets the same.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="IEEEtrantools.tex"
\documentclass{article}
\usepackage{IEEEtrantools}
\begin{document}
\begin{IEEEeqnarray}{rCl}a & = & b\end{IEEEeqnarray}
\end{document}
```
