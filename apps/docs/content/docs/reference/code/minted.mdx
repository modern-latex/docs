## Loading

```latex
\usepackage{minted}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\inputminted`, `\mintinline`, `\newminted`, `\setminted`, `\setmintedinline`, `\usemintedstyle`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="minted.tex" preview
\documentclass{article}
\usepackage{minted}
\begin{document}
\begin{minted}[linenos, frame=lines]{python}
print("hello")
\end{minted}
Inline \mintinline{c}{int x = 1;}.
\setminted{fontsize=\small}
\newminted{python}{}
\end{document}
```
