## Loading

```latex
\usepackage{fvextra}
```

Loads [`fancyvrb`](/docs/reference/code/fancyvrb) under this name, so a document asking for either gets the same.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="fvextra.tex" preview
\documentclass{article}
\usepackage{fvextra}
\begin{document}
\begin{Verbatim}[breaklines]a long line\end{Verbatim}
\end{document}
```
