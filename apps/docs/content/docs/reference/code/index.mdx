---
title: Code and Verbatim
description: Source code and text set exactly as typed.
---

12 packages. Each page says how mLaTeX supports one, lists the commands it gives, and shows a document that uses it, taken from mLaTeX's own tests so that it compiles as written.

| Name                                                  | What it does                                                                              |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| [`alltt`](/docs/reference/code/alltt)                 | Verbatim-like text with commands                                                          |
| [`comment`](/docs/reference/code/comment)             | Text left out                                                                             |
| [`fancyvrb`](/docs/reference/code/fancyvrb)           | Verbatim text with more to say about how                                                  |
| [`fvextra`](/docs/reference/code/fvextra)             | Fancyvrb extended                                                                         |
| [`listings`](/docs/reference/code/listings)           | Source code as it was typed                                                               |
| [`listingsutf8`](/docs/reference/code/listingsutf8)   | Listings in UTF-8                                                                         |
| [`lstautogobble`](/docs/reference/code/lstautogobble) | Listings without their indentation                                                        |
| [`minted`](/docs/reference/code/minted)               | Source code, which minted colors through Pygments                                         |
| [`moreverb`](/docs/reference/code/moreverb)           | More verbatim blocks                                                                      |
| [`spverbatim`](/docs/reference/code/spverbatim)       | Verbatim that breaks at spaces                                                            |
| [`upquote`](/docs/reference/code/upquote)             | Straight quotes in verbatim                                                               |
| [`verbatim`](/docs/reference/code/verbatim)           | The kernel's verbatim block made to read long files and a comment block that sets nothing |
