## Loading

```latex
\usepackage{listings}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\lstdefinelanguage`, `\lstdefinestyle`, `\lstinline`, `\lstinputlisting`, `\lstlistingname`, `\lstlistlistingname`, `\lstlistoflistings`, `\lstloadlanguages`, `\lstset`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="listings.tex" preview
\documentclass{article}
\usepackage{listings}
\begin{filecontents}{nothing.c}
int main(void) { return 0; }
\end{filecontents}
\begin{document}
\lstset{language=Python, basicstyle=\ttfamily\small, numbers=left, frame=single}
\begin{lstlisting}[caption={A function}, label=lst:f]
def f(x):
    return x * 2
\end{lstlisting}
Inline \lstinline|x = 1| and \lstinline[language=C]{int y;}.
\lstinputlisting[language=C]{nothing.c}
\lstdefinestyle{mine}{basicstyle=\small}
\end{document}
```
