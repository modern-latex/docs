## Loading

```latex
\usepackage{tabularx}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="tabularx.tex" preview
\documentclass{article}
\usepackage{tabularx}
\begin{document}
\begin{tabularx}{\textwidth}{lX>{\raggedleft\arraybackslash}X}
Term & A description long enough to wrap within its column and then some more words. & Right \\
\end{tabularx}
\end{document}
```
