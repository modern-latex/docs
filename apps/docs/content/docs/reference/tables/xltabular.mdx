## Loading

```latex
\usepackage{xltabular}
```

Loads [`tabularx`](/docs/reference/tables/tabularx) under this name, so a document asking for either gets the same.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="xltabular.tex" preview
\documentclass{article}
\usepackage{xltabular}
\begin{document}
\begin{xltabular}{\linewidth}{lX}
Term & a long description that wraps and may run over pages \\
\end{xltabular}
\end{document}
```
