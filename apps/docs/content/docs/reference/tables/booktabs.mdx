## Loading

```latex
\usepackage{booktabs}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\addlinespace`, `\bottomrule`, `\cmidrule`, `\midrule`, `\specialrule`, `\toprule`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="booktabs.tex"
\documentclass{article}
\usepackage{booktabs}
\begin{document}
\begin{tabular}{lr}
\toprule
Item & Price \\
\midrule
Tea & 2 \\
\cmidrule(lr){1-2}
Cake & 3 \\
\addlinespace
Total & 5 \\
\bottomrule
\end{tabular}
\end{document}
```
