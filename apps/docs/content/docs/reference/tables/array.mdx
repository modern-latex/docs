## Loading

```latex
\usepackage{array}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\arraybackslash`, `\newcolumntype`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="array.tex" preview
\documentclass{article}
\usepackage{array}
\begin{document}
\newcolumntype{C}[1]{>{\centering\arraybackslash}p{#1}}
\begin{tabular}{>{\bfseries}l|C{2cm}|m{2cm}|b{2cm}<{\,!}}
bold & centred & middle & bottom \\
\end{tabular}
\end{document}
```
