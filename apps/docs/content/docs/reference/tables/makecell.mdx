## Loading

```latex
\usepackage{makecell}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\cell`, `\makecell`, `\makegapedcells`, `\setcellgapes`, `\thead`, `\Two`, `\Xhline`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="makecell.tex" preview
\documentclass{article}
\usepackage{makecell}
\begin{document}
\begin{tabular}{|c|c|}\hline
\thead{Head\\Two} & \makecell{a\\b} \\\hline
\makecell[l]{left\\cell} & \makegapedcells x \\\hline
\end{tabular}
\end{document}
```
