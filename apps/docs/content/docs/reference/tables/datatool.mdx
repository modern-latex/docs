## Loading

```latex
\usepackage{datatool}
```

Built into mLaTeX. Loading it is accepted and reads nothing; what the package does is mLaTeX's own work, and any command of it that mLaTeX does not define comes from the glossary.

## Commands

`\DTLdisplaydb`, `\DTLforeach`, `\DTLnewdb`, `\DTLnewdbentry`, `\DTLnewrow`, `\name`, `\score`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="datatool.tex"
\documentclass{article}
\usepackage{datatool}
\begin{document}
\DTLnewdb{scores}
\DTLnewrow{scores}\DTLnewdbentry{scores}{Name}{Ada}\DTLnewdbentry{scores}{Score}{90}
\DTLnewrow{scores}\DTLnewdbentry{scores}{Name}{Alan}\DTLnewdbentry{scores}{Score}{85}
\DTLdisplaydb{scores}
\DTLforeach{scores}{\name=Name,\score=Score}{\name: \score. }
\end{document}
```
