## Loading

```latex
\usepackage{pgfplotstable}
```

Loads [`pgfplots`](/docs/reference/pictures/pgfplots) under this name, so a document asking for either gets the same.

## Commands

`\pgfplotstabletypeset`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="pgfplotstable.tex" preview
\documentclass{article}
\usepackage{pgfplotstable}
\begin{document}
\pgfplotstabletypeset{x y\\1 2\\3 4\\}
\end{document}
```
