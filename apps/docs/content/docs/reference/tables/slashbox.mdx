## Loading

```latex
\usepackage{slashbox}
```

Loads [`diagbox`](/docs/reference/tables/diagbox) under this name, so a document asking for either gets the same.

## Commands

`\backslashbox`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="slashbox.tex" preview
\documentclass{article}
\usepackage{slashbox}
\begin{document}
\begin{tabular}{|c|}\hline\backslashbox{a}{b}\\\hline\end{tabular}
\end{document}
```
