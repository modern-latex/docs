---
title: dcolumn
description: 'Numbers lined up on their decimal point.'
---

## Loading

```latex
\usepackage{dcolumn}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="dcolumn.tex" preview
\documentclass{article}
\usepackage{dcolumn}
\begin{document}
\begin{tabular}{D{.}{.}{2}}
1.25 \\ 10.5 \\ 100.75 \\
\end{tabular}
\end{document}
```

## Limits

<Callout type="warn">
  Numbers are centred, not aligned on the point.
</Callout>
