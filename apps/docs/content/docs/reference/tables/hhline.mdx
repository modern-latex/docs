---
title: hhline
description: 'Rules between rows, drawn column by column.'
---

## Loading

```latex
\usepackage{hhline}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\hhline`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="hhline.tex" preview
\documentclass{article}
\usepackage{hhline}
\begin{document}
\begin{tabular}{|c|c|}
\hhline{|=|=|}
a & b \\
\hhline{|-|-|}
\end{tabular}
\end{document}
```

## Limits

<Callout type="warn">
  Each rule is drawn across the whole table.
</Callout>
