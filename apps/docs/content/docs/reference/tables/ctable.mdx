## Loading

```latex
\usepackage{ctable}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\ctable`, `\FL`, `\LL`, `\ML`, `\NN`, `\setupctable`, `\tmark`, `\tnote`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="ctable.tex" preview
\documentclass{article}
\usepackage{ctable}
\begin{document}
\ctable[caption = Results, label = tab:r, pos = htbp]{lr}{\tnote{a note}}{
\FL Item & Value \ML Tea & 2\tmark \LL}
\end{document}
```
