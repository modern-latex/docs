## Loading

```latex
\usepackage{ltablex}
```

Loads [`tabularx`](/docs/reference/tables/tabularx) under this name, so a document asking for either gets the same.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="ltablex.tex"
\documentclass{article}
\usepackage{ltablex}
\begin{document}
\begin{tabularx}{\linewidth}{lX}a & a long cell that wraps\\\end{tabularx}
\end{document}
```
