## Loading

```latex
\usepackage{datetime}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\ampmtime`, `\currenttime`, `\formatdate`, `\formattime`, `\isodate`, `\longdate`, `\newdateformat`, `\numericdate`, `\oclock`, `\settimeformat`, `\shortdate`, `\shortmonthname`, `\THEDAY`, `\THEMONTH`, `\THEYEAR`, `\twodigits`, `\weekday`, `\xxivtime`, `\zellermonth`, `\zelleryear`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="datetime.tex" preview
\documentclass{article}
\usepackage{datetime}
\begin{document}
Today is \today, in ISO form \isodate, short \shortdate, and the time is \currenttime.
\end{document}
```
