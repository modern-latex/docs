---
title: fmtcount
description: 'Numbers and counters written in words and as ordinals.'
---

## Loading

```latex
\usepackage{fmtcount}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\FCordinal`, `\fmtcountsetoptions`, `\NUMBERstring`, `\Numberstring`, `\numberstring`, `\NUMBERstringnum`, `\Numberstringnum`, `\numberstringnum`, `\ordinal`, `\ordinalnum`, `\ORDINALstring`, `\Ordinalstring`, `\ordinalstring`, `\ORDINALstringnum`, `\Ordinalstringnum`, `\ordinalstringnum`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="fmtcount.tex"
\documentclass{article}
\usepackage{fmtcount}
\begin{document}
\ordinalnum{3}, \numberstringnum{12}, \Numberstringnum{5}, \ordinalstringnum{2}, \NUMBERstringnum{2026}; section \numberstring{section}.\section{One}
\end{document}
```
