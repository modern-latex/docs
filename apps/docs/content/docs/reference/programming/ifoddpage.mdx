## Loading

```latex
\usepackage{ifoddpage}
```

Loads [`changepage`](/docs/reference/documents/changepage) under this name, so a document asking for either gets the same.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="ifoddpage.tex" preview
\documentclass{article}
\usepackage{ifoddpage}
\begin{document}
\checkoddpage\ifoddpage odd\else even\fi.
\end{document}
```
