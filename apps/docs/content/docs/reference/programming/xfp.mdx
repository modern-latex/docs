---
title: xfp
description: 'Arithmetic in the document.'
---

## Loading

```latex
\usepackage{xfp}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over the engine's primitives.

## Commands

`\dimeval`, `\fpeval`, `\inteval`.

## Example

A document that uses it, from the engine's own tests, so it compiles as written:

```latex title="xfp.tex"
\documentclass{article}
\usepackage{xfp}
\begin{document}
\fpeval{2*(3+4)/5}, \fpeval{sqrt(2)}, \inteval{7*6}.
\end{document}
```
