## Loading

```latex
\usepackage{xparse}
```

Built into mLaTeX. Loading it is accepted and reads nothing; what the package does is mLaTeX's own work, and any command of it that mLaTeX does not define comes from the glossary.

## Commands

`\fresh`, `\IfBooleanTF`, `\maybe`, `\NewDocumentCommand`, `\NewDocumentEnvironment`, `\pair`, `\ProvideDocumentCommand`, `\RenewDocumentCommand`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="xparse.tex" preview
\documentclass{article}
\usepackage{xparse}
\begin{document}
\NewDocumentCommand{\pair}{O{x} m}{(#1, #2)}
\NewDocumentCommand{\maybe}{s m}{\IfBooleanTF{#1}{starred #2}{plain #2}}
\NewDocumentEnvironment{boxed}{m}{[#1: }{]}
\pair{y} \pair[a]{b} \maybe{one} \maybe*{two}
\begin{boxed}{tag} inside \end{boxed}
\RenewDocumentCommand{\pair}{m}{<#1>} \pair{z}
\ProvideDocumentCommand{\fresh}{}{fresh}\fresh
\end{document}
```
