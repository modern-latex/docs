## Loading

```latex
\usepackage{mwe}
```

Loads [`blindtext`](/docs/reference/programming/blindtext) under this name, so a document asking for either gets the same.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="mwe.tex" preview
\documentclass{article}
\usepackage{mwe}
\begin{document}
\blindtext \includegraphics[width=2cm]{example-image}
\end{document}
```
