## Loading

```latex
\usepackage{calc}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\half`, `\newlength`, `\settowidth`, `\widthof`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="calc.tex" preview
\documentclass{article}
\usepackage{calc}
\begin{document}
\newlength{\half}
\setlength{\half}{\textwidth/2 - 1cm}
\setcounter{page}{2*3}
\rule{\half}{1pt} \widthof{text} \settowidth{\half}{wide text}
\end{document}
```
