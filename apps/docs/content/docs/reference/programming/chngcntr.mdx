## Loading

```latex
\usepackage{chngcntr}
```

Built into mLaTeX. Loading it is accepted and reads nothing; what the package does is mLaTeX's own work, and any command of it that mLaTeX does not define comes from the glossary.

## Commands

`\counterwithin`, `\counterwithout`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="chngcntr.tex"
\documentclass{article}
\usepackage{chngcntr}
\begin{document}
\counterwithin{figure}{section}\counterwithout{equation}{section}\section{S}\begin{figure}[h]\caption{F}\end{figure}
\end{document}
```
