## Loading

```latex
\usepackage{tikz-qtree}
```

Loads [`tikz`](/docs/reference/pictures/tikz) under this name, so a document asking for either gets the same.

## Commands

`\Tree`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="tikz-qtree.tex" preview
\documentclass{article}
\usepackage{tikz-qtree}
\usepackage{tikz}
\begin{document}
\begin{tikzpicture}\Tree [.S NP VP ]\end{tikzpicture}
\end{document}
```
