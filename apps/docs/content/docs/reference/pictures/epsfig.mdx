## Loading

```latex
\usepackage{epsfig}
```

Loads [`graphicx`](/docs/reference/pictures/graphicx) under this name, so a document asking for either gets the same.

## Commands

`\epsfig`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="epsfig.tex" preview
\documentclass{article}
\usepackage{epsfig}
\begin{document}
\epsfig{file=example-image,width=2cm}
\end{document}
```
