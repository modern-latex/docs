## Loading

```latex
\usepackage{xypic}
```

Loads [`xy`](/docs/reference/pictures/xy) under this name, so a document asking for either gets the same.

## Commands

`\ar`, `\xymatrix`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="xypic.tex"
\documentclass{article}
\usepackage{xypic}
\begin{document}
\xymatrix{A \ar[r] & B}
\end{document}
```
