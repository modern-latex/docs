title: axodraw2

---

## Loading

```latex
\usepackage{axodraw2}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\ArrowLine`, `\axopicture`, `\CArc`, `\DashLine`, `\endaxopicture`, `\GCirc`, `\Gluon`, `\Line`, `\Photon`, `\SetColor`, `\SetScale`, `\SetWidth`, `\Text`, `\Vertex`, `\ZigZag`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="axodraw2.tex" preview
\documentclass{article}
\usepackage{axodraw2}
\begin{document}
\begin{axopicture}(100,50)\Line(0,0)(100,50)\Photon(0,50)(100,0){3}{5}\end{axopicture}
\end{document}
```
