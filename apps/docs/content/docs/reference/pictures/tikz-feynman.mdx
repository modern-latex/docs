## Loading

```latex
\usepackage{tikz-feynman}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\diagram`, `\endfeynman`, `\feynman`, `\feynmandiagram`, `\feynmanset`, `\vertex`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="tikz-feynman.tex" preview
\documentclass{article}
\usepackage{tikz-feynman}
\begin{document}
\feynmandiagram[horizontal=a to b]{i1 -- [fermion] a -- [photon] b -- [fermion] f1};
\end{document}
```
