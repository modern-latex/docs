## Loading

```latex
\usepackage{svg}
```

Built into mLaTeX. Loading it is accepted and reads nothing; what the package does is mLaTeX's own work, and any command of it that mLaTeX does not define comes from the glossary.

## Commands

`\includesvg`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="svg.tex"
\documentclass{article}
\usepackage{svg}
\begin{filecontents*}{drawing.svg}
<svg xmlns="http://www.w3.org/2000/svg" width="20" height="10"><rect width="20" height="10"/></svg>
\end{filecontents*}
\begin{document}
\includesvg[width=2cm]{drawing}
\end{document}
```
