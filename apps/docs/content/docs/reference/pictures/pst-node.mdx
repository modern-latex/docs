title: pst-node
description: 'Nodes in the text and the lines between them.'
---

## Loading

```latex
\usepackage{pst-node}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\cnode`, `\naput`, `\nbput`, `\ncangle`, `\ncarc`, `\ncbar`, `\nccurve`, `\ncline`, `\ncloop`, `\ncput`, `\pnode`, `\Rnode`, `\rnode`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="pst-node.tex" preview
\documentclass{article}
\usepackage{pst-node}
\begin{document}
\rnode{A}{A} and \rnode{B}{B} \ncline{A}{B}
\end{document}
```

## Limits

<Callout type="warn">
  Connections between nodes are not drawn.
</Callout>
