## Loading

```latex
\usepackage{smartdiagram}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\smartdiagram`, `\smartdiagramadd`, `\smartdiagramanimated`, `\smartdiagramconnect`, `\smartdiagramset`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="smartdiagram.tex" preview
\documentclass{article}
\usepackage{smartdiagram}
\begin{document}
\smartdiagram[flow diagram:horizontal]{Plan, Build, Test, Ship}
\end{document}
```

## Limits

<Callout type="warn">
  Items are joined by arrows.
</Callout>
