---

## Loading

```latex
\usepackage{feynmp}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\csname`, `\endfmffile`, `\endfmfgraph`, `\fmf`, `\fmfbottom`, `\fmfdot`, `\fmffile`, `\fmffreeze`, `\fmfgraph`, `\fmflabel`, `\fmfleft`, `\fmfpen`, `\fmfright`, `\fmfset`, `\fmfstraight`, `\fmftop`, `\fmfv`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="feynmp.tex" preview
\documentclass{article}
\usepackage{feynmp}
\begin{document}
\begin{fmffile}{diagram}\begin{fmfgraph}(40,25)\fmfleft{i}\fmfright{o}\fmf{fermion}{i,o}\end{fmfgraph}\end{fmffile}
\end{document}
```

## Limits

<Callout type="warn">
  Diagrams are not drawn; their place is kept.
</Callout>
