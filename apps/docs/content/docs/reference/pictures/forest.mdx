## Loading

```latex
\usepackage{forest}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\forestset`, `\useforestlibrary`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="forest.tex"
\documentclass{article}
\usepackage{forest}
\begin{document}
\begin{forest}
[S [NP [Det [the]] [N [cat]]] [VP [V [sat]]]]
\end{forest}
\end{document}
```

## Limits

<Callout type="warn">
  Its own placement options are ignored.
</Callout>
