## Loading

```latex
\usepackage{bxcoloremoji}
```

Built into mLaTeX. Loading it is accepted and reads nothing; what the package does is mLaTeX's own work, and any command of it that mLaTeX does not define comes from the glossary.

## Commands

`\coloremoji`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="bxcoloremoji.tex" preview
\documentclass{article}
\usepackage{bxcoloremoji}
\begin{document}
\coloremoji{😀}
\end{document}
```
