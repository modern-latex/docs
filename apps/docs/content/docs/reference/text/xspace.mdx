---
title: xspace
description: 'A space after a command unless punctuation follows.'
---

## Loading

```latex
\usepackage{xspace}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\eg`, `\xspace`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="xspace.tex" preview
\documentclass{article}
\usepackage{xspace}
\begin{document}
\newcommand{\eg}{e.g.\xspace}\eg this, and \eg, that.
\end{document}
```
