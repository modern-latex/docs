## Loading

```latex
\usepackage{xcolor}
```

Built into mLaTeX. Loading it is accepted and reads nothing; what the package does is mLaTeX's own work, and any command of it that mLaTeX does not define comes from the glossary.

## Commands

`\colorbox`, `\colorlet`, `\definecolor`, `\fcolorbox`, `\pagecolor`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="xcolor.tex" preview
\documentclass{article}
\usepackage[dvipsnames,table]{xcolor}
\begin{document}
\definecolor{brand}{RGB}{30,100,200}
\colorlet{light}{brand!20}
\textcolor{brand}{Brand}, \textcolor{red!50!blue}{mixed}, \colorbox{light}{boxed}, \fcolorbox{red}{yellow}{framed}, {\color{teal} teal}.
\pagecolor{white}
\end{document}
```
