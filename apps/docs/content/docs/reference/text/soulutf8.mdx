## Loading

```latex
\usepackage{soulutf8}
```

Loads [`soul`](/docs/reference/text/soul) under this name, so a document asking for either gets the same.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="soulutf8.tex"
\documentclass{article}
\usepackage{soulutf8}
\begin{document}
\hl{highlighted} café.
\end{document}
```
