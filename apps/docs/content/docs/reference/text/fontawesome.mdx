## Loading

```latex
\usepackage{fontawesome}
```

Loads [`fontawesome5`](/docs/reference/text/fontawesome5) under this name, so a document asking for either gets the same.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="fontawesome.tex" preview
\documentclass{article}
\usepackage{fontawesome}
\begin{document}
\faGithub{} \faEnvelope{} \faTwitter
\end{document}
```
