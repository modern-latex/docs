title: tipa
description: 'The International Phonetic Alphabet.'
---

## Loading

```latex
\usepackage{tipa}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\textae`, `\textbari`, `\textbaru`, `\textbeta`, `\textchi`, `\textctc`, `\textepsilon`, `\textesh`, `\texteth`, `\textfishhookr`, `\textgamma`, `\textglotstop`, `\textipa`, `\textipaeng`, `\textlengthmark`, `\textltailn`, `\textopeno`, `\textprimstress`, `\textrhookschwa`, `\textschwa`, `\textsci`, `\textscripta`, `\textscy`, `\textsecstress`, `\texttheta`, `\textturna`, `\textturnr`, `\textturnv`, `\textupsilon`, `\textyogh`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="tipa.tex" preview
\documentclass{article}
\usepackage{tipa}
\begin{document}
\textipa{[f@"nEtIks]} and \textschwa{} \textesh.
\end{document}
```
