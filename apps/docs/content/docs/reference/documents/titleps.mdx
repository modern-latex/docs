## Loading

```latex
\usepackage{titleps}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\footrule`, `\footrulewidth`, `\headrule`, `\headrulewidth`, `\newpagestyle`, `\pagestyle`, `\renewpagestyle`, `\setfoot`, `\setfootrule`, `\sethead`, `\setheadrule`, `\setmarks`, `\settitlemarks`, `\thepage`, `\widenhead`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="titleps.tex"
\documentclass{article}
\usepackage{titleps}
\begin{document}
\newpagestyle{main}{\sethead{Left}{}{\thepage}}\pagestyle{main}Text.
\end{document}
```
