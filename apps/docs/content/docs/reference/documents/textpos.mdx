---
title: textpos
description: 'A block of text at a place on the page.'
---

## Loading

```latex
\usepackage{textpos}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\csname`, `\endtextblock`, `\textblock`, `\textblockcolor`, `\textblockcolour`, `\textblockorigin`, `\textblockrulecolour`, `\TPGrid`, `\TPshowboxesfalse`, `\TPshowboxestrue`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="textpos.tex" preview
\documentclass{article}
\usepackage[absolute]{textpos}
\begin{document}
\begin{textblock*}{3cm}(2cm,2cm)Placed text.\end{textblock*}\begin{textblock}{3}(1,1)More.\end{textblock}
\end{document}
```

## Limits

<Callout type="warn">
  The block is set where it stands, not at its position.
</Callout>
