## Loading

```latex
\usepackage{setspace}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\baselinestretch`, `\doublespace`, `\doublespacing`, `\enddoublespace`, `\endonehalfspace`, `\endsinglespace`, `\endspacing`, `\onehalfspace`, `\onehalfspacing`, `\setstretch`, `\singlespace`, `\SingleSpacing`, `\singlespacing`, `\spacing`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="setspace.tex" preview
\documentclass{article}
\usepackage{setspace}
\begin{document}
\onehalfspacing
One and a half.
\doublespacing
Double.
\begin{singlespace}
Single.
\end{singlespace}
\setstretch{1.2}
\begin{spacing}{1.5} Spaced. \end{spacing}
\end{document}
```
