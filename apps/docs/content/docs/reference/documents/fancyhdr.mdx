## Loading

```latex
\usepackage{fancyhdr}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\cfoot`, `\chead`, `\fancyfoot`, `\fancyhead`, `\fancyhf`, `\fancypagestyle`, `\footrulewidth`, `\headrulewidth`, `\lfoot`, `\lhead`, `\pagestyle`, `\rfoot`, `\rhead`, `\thepage`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="fancyhdr.tex" preview
\documentclass{article}
\usepackage{fancyhdr}
\begin{document}
\pagestyle{fancy}
\fancyhf{}
\fancyhead[L]{Left head}
\fancyhead[R]{\thepage}
\fancyfoot[C]{Centre foot}
\renewcommand{\headrulewidth}{0.4pt}
\renewcommand{\footrulewidth}{0.4pt}
\lhead{Old left}\rhead{Old right}\cfoot{\thepage}
\fancypagestyle{plain}{\fancyhf{}\fancyfoot[C]{\thepage}}
Body text.
\end{document}
```
