## Loading

```latex
\usepackage{abstract}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\abstracttitle`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="abstract.tex" preview
\documentclass{article}
\usepackage[runin]{abstract}
\renewcommand{\abstractname}{Summary}
\begin{document}
\begin{abstract}
The abstract, headed as the package heads it.
\end{abstract}
\end{document}
```
