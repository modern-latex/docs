---
title: parskip
description: 'Paragraphs set apart by space rather than by indentation, half a line between them.'
---

## Loading

```latex
\usepackage{parskip}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="parskip.tex" preview
\documentclass{article}
\usepackage[parfill]{parskip}
\begin{document}
A first paragraph.

A second one, set apart by space.
\end{document}
```
