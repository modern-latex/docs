## Loading

```latex
\usepackage{changepage}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\adjustwidth`, `\changepage`, `\changetext`, `\checkoddpage`, `\csname`, `\easypagecheck`, `\else`, `\endadjustwidth`, `\fi`, `\ifoddpage`, `\strictpagecheck`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="changepage.tex"
\documentclass{article}
\usepackage[strict]{changepage}
\begin{document}
\begin{adjustwidth}{1cm}{1cm}Narrower text.\end{adjustwidth}\checkoddpage\ifoddpage odd\else even\fi
\end{document}
```

## Limits

<Callout type="warn">
  Every page counts as a right-hand page.
</Callout>
