## Loading

```latex
\usepackage{scrlayer-scrpage}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\addtokomafont`, `\automark`, `\cehead`, `\cfoot`, `\chead`, `\clearpairofpagestyles`, `\clearscrheadfoot`, `\clearscrheadings`, `\cofoot`, `\cohead`, `\headmark`, `\ifoot`, `\ihead`, `\KOMAoptions`, `\lehead`, `\lofoot`, `\lohead`, `\manualmark`, `\ofoot`, `\ohead`, `\pagemark`, `\pagestyle`, `\ps`, `\rehead`, `\rofoot`, `\rohead`, `\setkomafont`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="scrlayer-scrpage.tex" preview
\documentclass{article}
\usepackage{scrlayer-scrpage}
\begin{document}
\pagestyle{scrheadings}\ihead{Inner}\ohead{Outer}\cfoot{\pagemark}\automark{section}Text.
\end{document}
```
