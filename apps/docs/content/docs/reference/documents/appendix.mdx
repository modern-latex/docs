## Loading

```latex
\usepackage{appendix}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\addappheadtotoc`, `\appendixname`, `\appendixpage`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="appendix.tex"
\documentclass{article}
\usepackage[toc,page]{appendix}
\begin{document}
\section{Main}
Text.
\begin{appendices}
\section{First appendix}
Details.
\end{appendices}
\end{document}
```
