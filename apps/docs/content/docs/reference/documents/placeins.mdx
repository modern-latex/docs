---
title: placeins
description: '\FloatBarrier, which keeps floats from passing it.'
---

## Loading

```latex
\usepackage{placeins}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\FloatBarrier`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="placeins.tex" preview
\documentclass{article}
\usepackage[section]{placeins}
\begin{document}
\section{One}
\begin{figure}[htbp]\centering\rule{1cm}{1cm}\caption{A}\end{figure}
\FloatBarrier
\section{Two}
\end{document}
```
