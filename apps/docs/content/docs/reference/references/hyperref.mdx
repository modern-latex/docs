## Loading

```latex
\usepackage{hyperref}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\autoref`, `\belowpdfbookmark`, `\currentpdfbookmark`, `\doi`, `\href`, `\hyperbaseurl`, `\hyperdef`, `\hyperlink`, `\hyperref`, `\hypersetup`, `\hypertarget`, `\nolinkurl`, `\ORCID`, `\orcid`, `\pdfbookmark`, `\pdfstringdefDisableCommands`, `\phantomsection`, `\subpdfbookmark`, `\texorpdfstring`, `\url`, `\urldef`, `\urlstyle`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="hyperref.tex" preview
\documentclass{article}
\usepackage{hyperref}
\begin{document}
\hypersetup{colorlinks=true, linkcolor=blue, urlcolor=cyan, pdftitle={A Title}, pdfauthor={Me}}
\section{Start}\label{sec:start}
\href{https://example.org}{a link}, \url{https://example.org}, \nolinkurl{example.org},
\autoref{sec:start}, \hyperref[sec:start]{back}, \hyperlink{here}{to here}, \hypertarget{here}{here},
\texorpdfstring{$x$}{x}, \pdfbookmark[1]{Bookmark}{bm}, \phantomsection.
\end{document}
```
