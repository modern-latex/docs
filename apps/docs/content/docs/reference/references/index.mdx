## Loading

```latex
\usepackage{index}
```

Loads [`makeidx`](/docs/reference/references/makeidx) under this name, so a document asking for either gets the same.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="index.tex" preview
\documentclass{article}
\usepackage{index}
\makeindex
\begin{document}
Word\index{word}.\printindex
\end{document}
```
