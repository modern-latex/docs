---
title: orcidlink
description: 'An author''s ORCID, which the page, carrying no links, leaves out.'
---

## Loading

```latex
\usepackage{orcidlink}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\orcidlink`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="orcidlink.tex" preview
\documentclass{article}
\usepackage{orcidlink}
\begin{document}
Ada Lovelace \orcidlink{0000-0002-1825-0097}
\end{document}
```

## Limits

<Callout type="warn">
  The ORCID mark is left out.
</Callout>
