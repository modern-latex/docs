## Loading

```latex
\usepackage{nomencl}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\makenomenclature`, `\nomenclature`, `\printnomenclature`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="nomencl.tex" preview
\documentclass{article}
\usepackage{nomencl}
\begin{document}
\makenomenclature
$c$\nomenclature{$c$}{Speed of light}
\printnomenclature
\end{document}
```

## Limits

<Callout type="warn">
