## Loading

```latex
\usepackage{glossaries-extra}
```

Loads [`glossaries`](/docs/reference/references/glossaries) under this name, so a document asking for either gets the same.

## Commands

`\newabbreviation`, `\printunsrtglossaries`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="glossaries-extra.tex" preview
\documentclass{article}
\usepackage[abbreviations]{glossaries-extra}
\begin{document}
\newglossaryentry{api}{name={API}, description={an interface}}
\newabbreviation{html}{HTML}{hypertext markup language}
\makeglossaries
\gls{api}, \gls{html}, \gls{html}.
\printunsrtglossaries
\end{document}
```
