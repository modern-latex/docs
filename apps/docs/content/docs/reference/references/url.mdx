## Loading

```latex
\usepackage{url}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\burl`, `\burlalt`, `\path`, `\url`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="url.tex" preview
\documentclass{article}
\usepackage[hyphens]{url}
\begin{document}
\url{https://example.org/a_b~c}, \path{C:/files}, \urlstyle{same}\url{x.org}.
\end{document}
```

## Limits

<Callout type="warn">
  A `%` or `#` in an address must be escaped.
</Callout>
