## Loading

```latex
\usepackage{splitidx}
```

Loads [`imakeidx`](/docs/reference/references/imakeidx) under this name, so a document asking for either gets the same.

## Commands

`\newindex`, `\printsubindex`, `\sindex`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="splitidx.tex"
\documentclass{article}
\usepackage{splitidx}
\makeindex\newindex[Names]{names}
\begin{document}
Word\sindex[names]{word}.\printsubindex
\end{document}
```
