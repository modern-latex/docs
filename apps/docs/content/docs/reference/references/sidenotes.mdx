title: sidenotes
description: 'Notes, citations, figures and tables in the margin — a note numbered with the footnotes, its mark in the text and the note beside it.'
---

## Loading

```latex
\usepackage{sidenotes}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\endmarginfigure`, `\endmargintable`, `\endwidefigure`, `\marginfigure`, `\margintable`, `\sidecaption`, `\sidecite`, `\sidenote`, `\sidenotemark`, `\sidenotetext`, `\widefigure`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="sidenotes.tex" preview
\documentclass{article}
\usepackage{sidenotes}
\begin{document}
Text\sidenote{A side note.} and \sidecite{a}. \begin{marginfigure}\rule{1cm}{1cm}\caption{Margin}\end{marginfigure}
\end{document}
```
