## Loading

```latex
\usepackage{xurl}
```

Loads [`url`](/docs/reference/references/url) under this name, so a document asking for either gets the same.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="xurl.tex"
\documentclass{article}
\usepackage{xurl}
\begin{document}
\url{https://example.org/a/very/long/address}
\end{document}
```
