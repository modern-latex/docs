## Loading

```latex
\usepackage{titletoc}
```

Built into the engine. Loading it is accepted and reads nothing; what the package does is the engine's own work, and any command of it that the engine does not define comes from the glossary.

## Commands

`\contentspage`, `\tableofcontents`, `\thecontentslabel`, `\titlecontents`.

## Example

A document that uses it, from the engine's own tests, so it compiles as written:

```latex title="titletoc.tex"
\documentclass{article}
\usepackage{titletoc}
\begin{document}
\titlecontents{section}[0em]{}{\thecontentslabel\quad}{}{\titlerule*[1pc]{.}\contentspage}\tableofcontents\section{One}
\end{document}
```
