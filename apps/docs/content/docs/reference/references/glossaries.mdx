title: glossaries
description: 'Terms defined once and used by name.'
---

## Loading

```latex
\usepackage{glossaries}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\acrfull`, `\acrlong`, `\acrshort`, `\Gls`, `\gls`, `\glsentrydesc`, `\glsentryname`, `\Glspl`, `\glspl`, `\glsresetall`, `\longnewglossaryentry`, `\makeglossaries`, `\newacronym`, `\newglossaryentry`, `\printglossaries`, `\printglossary`, `\setacronymstyle`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="glossaries.tex"
\documentclass{article}
\usepackage{glossaries}
\begin{document}
\newglossaryentry{latex}{name={LaTeX}, description={a document preparation system}}
\newacronym{gcd}{GCD}{greatest common divisor}
\makeglossaries
\gls{latex}, \Gls{latex}, \glspl{latex}, \acrshort{gcd}, \acrlong{gcd}, \acrfull{gcd}, \gls{gcd}.
\printglossaries
\end{document}
```
