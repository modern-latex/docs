## Loading

```latex
\usepackage{todonotes}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\listoftodos`, `\missingfigure`, `\todo`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="todonotes.tex"
\documentclass{article}
\usepackage{todonotes}
\begin{document}
Text.\todo{Check this.} \todo[inline]{An inline note.} \missingfigure{A figure to come.} \listoftodos
\end{document}
```
