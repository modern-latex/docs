---
title: biblatex
description: 'Bibliographies from .bib files in biblatex''s styles.'
---

## Loading

```latex
\usepackage{biblatex}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\addbibresource`, `\AtEveryBibitem`, `\autocite`, `\bibliographysetup`, `\citetitle`, `\DeclareFieldFormat`, `\defbibheading`, `\footcite`, `\fullcite`, `\parencite`, `\printbibliography`, `\textcite`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="biblatex.tex" preview
\documentclass{article}
\usepackage[style=authoryear,backend=biber]{biblatex}
\begin{filecontents}{refs.bib}
@book{knuth, author = {Donald Knuth}, title = {The TeXbook}, year = {1984}, publisher = {Addison-Wesley}}
@book{lamport, author = {Leslie Lamport}, title = {LaTeX: A Document Preparation System}, year = {1994}, publisher = {Addison-Wesley}}
\end{filecontents}
\addbibresource{refs.bib}
\begin{document}
As \textcite{knuth} shows \parencite{knuth}; see also \cite{lamport} and \autocite{knuth}.
\printbibliography
\end{document}
```
