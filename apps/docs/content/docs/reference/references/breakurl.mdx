## Loading

```latex
\usepackage{breakurl}
```

Loads [`url`](/docs/reference/references/url) under this name, so a document asking for either gets the same.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="breakurl.tex" preview
\documentclass{article}
\usepackage{breakurl}
\begin{document}
\burl{https://example.org}
\end{document}
```
