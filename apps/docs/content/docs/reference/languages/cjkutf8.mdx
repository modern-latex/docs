## Loading

```latex
\usepackage{CJKutf8}
```

Loads [`CJK`](/docs/reference/languages/cjk) under this name, so a document asking for either gets the same.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="CJKutf8.tex" preview
\documentclass{article}
\usepackage{CJKutf8}
\begin{document}
\begin{CJK*}{UTF8}{gbsn}中文\end{CJK*}
\end{document}
```
