---

8 packages. Each page says how mLaTeX supports one, lists the commands it gives, and shows a document that uses it, taken from mLaTeX's own tests so that it compiles as written.

| Name                                                   | What it does                                                                                                                 |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| [`babel`](/docs/reference/languages/babel)             | The languages a document is written in, named as its options — the last the one it is in, those before it the ones it quotes |
| [`bidi`](/docs/reference/languages/bidi)               | Paragraphs right to left or left to right, with `\setRTL` and `\setLTR`                                                      |
| [`CJK`](/docs/reference/languages/cjk)                 | Chinese, Japanese and Korean text                                                                                            |
| [`CJKutf8`](/docs/reference/languages/cjkutf8)         | CJK in UTF-8                                                                                                                 |
| [`ctex`](/docs/reference/languages/ctex)               | Chinese documents                                                                                                            |
| [`polyglossia`](/docs/reference/languages/polyglossia) | Languages named by command, each with a command and an environment of its own                                                |
| [`translator`](/docs/reference/languages/translator)   | Words translated for packages                                                                                                |
| [`xeCJK`](/docs/reference/languages/xecjk)             | CJK with XeLaTeX                                                                                                             |
