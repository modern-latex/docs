title: polyglossia
description: 'Languages named by command, each with a command and an environment of its own.'
---

## Loading

```latex
\usepackage{polyglossia}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\disablehyphenation`, `\enablehyphenation`, `\foreignlanguage`, `\iflanguageloaded`, `\iflanguageoption`, `\languagename`, `\resetdefaultlanguage`, `\selectbackgroundlanguage`, `\selectlanguage`, `\setdefaultlanguage`, `\setlanguagealias`, `\setmainlanguage`, `\setotherlanguage`, `\setotherlanguages`, `\textfrench`, `\textgerman`, `\textlang`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="polyglossia.tex" preview
\documentclass{article}
\usepackage{polyglossia}
\setmainlanguage{english}
\setotherlanguages{french,german}
\begin{document}
Text in English. \textfrench{Du fran\c{c}ais.} \textgerman{Deutsch.}
\begin{french}
Un paragraphe.
\end{french}
\end{document}
```
