## Loading

```latex
\usepackage{fontspec}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\addfontfeature`, `\addfontfeatures`, `\defaultfontfeatures`, `\fontspec`, `\greek`, `\IfFontExistsTF`, `\newfontface`, `\newfontfamily`, `\newfontlanguage`, `\newfontscript`, `\renewfontfamily`, `\setfontfamily`, `\setmainfont`, `\setmathfont`, `\setmonofont`, `\setromanfont`, `\setsansfont`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="fontspec.tex"
\documentclass{article}
\usepackage{fontspec}
\begin{document}
\setmainfont{Times New Roman}
\setsansfont{Arial}
\setmonofont{Courier New}
\newfontfamily\greek{GFS Didot}
Main text, \textsf{sans}, \texttt{mono}, {\greek Greek}, \addfontfeature{Numbers=OldStyle}1234.
\end{document}
```

## Limits

<Callout type="warn">
  A font with nothing near it among the faces mLaTeX carries is not used; the text keeps its face, with a warning.
</Callout>
