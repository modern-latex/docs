## Loading

```latex
\documentclass{scrartcl}
```

A class of mLaTeX's own: its paper, type size and columns are read from its options.

## Commands

`\addsec`, `\minisec`, `\subtitle`, `\textsubscript`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="scrartcl.tex" preview
\documentclass[paper=a4,fontsize=11pt]{scrartcl}
\begin{document}
\title{A KOMA Article}
\subtitle{With a subtitle}
\author{Hedy Lamarr}
\maketitle
\addsec{Unnumbered section}
\section{Numbered}
\minisec{A mini heading}
Text \textsubscript{low}.
\end{document}
```
