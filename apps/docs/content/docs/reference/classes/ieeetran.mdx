## Loading

```latex
\documentclass{IEEEtran}
```

A class of mLaTeX's own: its paper, type size and columns are read from its options.

## Commands

`\IEEEauthorblockA`, `\IEEEauthorblockN`, `\IEEEPARstart`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="IEEEtran.tex" preview
\documentclass[conference]{IEEEtran}
\begin{document}
\title{A Conference Paper}
\author{\IEEEauthorblockN{Ada Lovelace}\IEEEauthorblockA{Analytical Engines Ltd.\\ London}}
\maketitle
\begin{abstract}
We describe a machine.
\end{abstract}
\begin{IEEEkeywords}
engines, computation
\end{IEEEkeywords}
\section{Introduction}
\IEEEPARstart{T}{his} paper opens with a large initial. As shown in Table~\ref{tab:a}.
\begin{table}[htbp]
\caption{Results}\label{tab:a}
\centering
\begin{tabular}{cc}\hline a & b\\\hline\end{tabular}
\end{table}
\section{Method}
\subsection{Setup}
Text in two columns.
\end{document}
```
