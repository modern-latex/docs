## Loading

```latex
\documentclass{elsarticle}
```

A class of mLaTeX's own: its paper, type size and columns are read from its options.

## Commands

`\address`, `\sep`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="elsarticle.tex" preview
\documentclass[preprint,12pt]{elsarticle}
\begin{document}
\begin{frontmatter}
\title{An Elsevier Article}
\author[a]{Marie Curie}
\address[a]{Sorbonne, Paris}
\begin{abstract}
Radioactivity.
\end{abstract}
\begin{keyword}
radium \sep polonium
\end{keyword}
\end{frontmatter}
\section{Introduction}
Text.
\end{document}
```
