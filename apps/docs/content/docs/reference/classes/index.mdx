15 classes. Each page says how mLaTeX supports one, lists the commands it gives, and shows a document that uses it, taken from mLaTeX's own tests so that it compiles as written.

| [`elsarticle`](/docs/reference/classes/elsarticle) | Elsevier journal articles                    |
| [`IEEEtran`](/docs/reference/classes/ieeetran)     | IEEE conference and journal papers           |
| [`letter`](/docs/reference/classes/letter)         | LaTeX's letter class                         |
| [`llncs`](/docs/reference/classes/llncs)           | Springer's Lecture Notes in Computer Science |
| [`revtex4`](/docs/reference/classes/revtex4)       | APS and AIP papers, first release            |
| [`revtex4-1`](/docs/reference/classes/revtex4-1)   | APS and AIP papers                           |
| [`revtex4-2`](/docs/reference/classes/revtex4-2)   | APS and AIP papers                           |
| [`scrartcl`](/docs/reference/classes/scrartcl)     | KOMA-Script's article                        |
| [`scrbook`](/docs/reference/classes/scrbook)       | KOMA-Script's book                           |
