## Loading

```latex
\documentclass{amsart}
```

A class of mLaTeX's own: its paper, type size and columns are read from its options.

## Commands

`\address`, `\keywords`, `\ln`, `\sim`, `\subjclass`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="amsart.tex" preview
\documentclass{amsart}
\begin{document}
\title{On Numbers}
\author{Emmy Noether}
\address{University of G\"ottingen}
\email{noether@example.org}
\subjclass[2020]{11A41}
\keywords{primes}
\begin{abstract}
A short note.
\end{abstract}
\maketitle
\section{Primes}
\begin{equation}
\pi(x) \sim \frac{x}{\ln x}.
\end{equation}
\end{document}
```
