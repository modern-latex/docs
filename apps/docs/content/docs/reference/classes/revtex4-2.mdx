## Loading

```latex
\documentclass{revtex4-2}
```

A class of mLaTeX's own: its paper, type size and columns are read from its options.

## Commands

`\affiliation`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="revtex4-2.tex" preview
\documentclass[aps,prl,reprint]{revtex4-2}
\begin{document}
\title{A Physical Review Letter}
\author{Paul Dirac}
\affiliation{University of Cambridge}
\date{\today}
\begin{abstract}
Antimatter.
\end{abstract}
\maketitle
\section{Introduction}
Text.
\begin{acknowledgments}
We thank everyone.
\end{acknowledgments}
\end{document}
```
