## Loading

```latex
\documentclass{letter}
```

A class of mLaTeX's own: its paper, type size and columns are read from its options.

## Commands

`\address`, `\cc`, `\closing`, `\encl`, `\opening`, `\ps`, `\signature`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="letter.tex"
\documentclass{letter}
\begin{document}
\signature{Jane Austen}
\address{Chawton\\ Hampshire}
\begin{letter}{Mr.\ Darcy\\ Pemberley}
\opening{Dear Sir,}
Your letter arrived.
\closing{Yours faithfully,}
\ps{P.S. The weather is fine.}
\encl{A map}
\cc{Mr.\ Bingley}
\end{letter}
\end{document}
```
