## Loading

```latex
\documentclass{scrbook}
```

A class of mLaTeX's own: its paper, type size and columns are read from its options.

## Commands

`\backmatter`, `\chapter`, `\frontmatter`, `\mainmatter`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="scrbook.tex" preview
\documentclass{scrbook}
\begin{document}
\frontmatter
\title{A KOMA Book}
\author{Ada Lovelace}
\maketitle
\mainmatter
\chapter{Engines}
Text.
\backmatter
\chapter{Afterword}
Fin.
\end{document}
```
