## Loading

```latex
\documentclass{llncs}
```

A class of mLaTeX's own: its paper, type size and columns are read from its options.

## Commands

`\email`, `\inst`, `\institute`, `\keywords`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="llncs.tex" preview
\documentclass{llncs}
\begin{document}
\title{A Springer LNCS Paper}
\author{Kurt G\"odel\inst{1}}
\institute{Institute for Advanced Study, Princeton\\\email{goedel@example.org}}
\maketitle
\begin{abstract}
Incompleteness.
\keywords{logic \and arithmetic}
\end{abstract}
\section{Introduction}
\begin{theorem}
Every consistent system is incomplete.
\end{theorem}
\begin{proof}
By diagonalisation.
\end{proof}
\end{document}
```
