## Loading

```latex
\usepackage{float}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\floatname`, `\floatplacement`, `\floatrestyled`, `\floatstyle`, `\listof`, `\newfloat`, `\restylefloat`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="float.tex"
\documentclass{article}
\usepackage{float}
\begin{document}
\floatstyle{ruled}
\newfloat{program}{htbp}{lop}
\floatname{program}{Program}
\begin{figure}[H]
\centering\rule{1cm}{1cm}
\caption{Here, exactly.}
\end{figure}
\begin{program}[H]
\caption{A new float}
Code.
\end{program}
\end{document}
```
