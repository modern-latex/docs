## Loading

```latex
\usepackage{algorithmicx}
```

Loads [`algpseudocode`](/docs/reference/floats/algpseudocode) under this name, so a document asking for either gets the same.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="algorithmicx.tex" preview
\documentclass{article}
\usepackage{algorithmicx}
\usepackage{algpseudocode}
\begin{document}
\begin{algorithmic}\State $x \gets 1$\end{algorithmic}
\end{document}
```
