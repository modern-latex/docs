## Loading

```latex
\usepackage{wrapfig}
```

Built into mLaTeX. Loading it is accepted and reads nothing; what the package does is mLaTeX's own work, and any command of it that mLaTeX does not define comes from the glossary.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="wrapfig.tex"
\documentclass{article}
\usepackage{wrapfig}
\begin{document}
\begin{wrapfigure}{r}{0.3\textwidth}
\centering\rule{2cm}{2cm}
\caption{Wrapped}
\end{wrapfigure}
Text that flows beside the figure for a while, and then continues below it as text does.
\begin{wraptable}{l}{3cm}\centering\begin{tabular}{c}a\end{tabular}\caption{A wrapped table}\end{wraptable}
\end{document}
```
