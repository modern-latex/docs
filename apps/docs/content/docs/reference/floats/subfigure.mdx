## Loading

```latex
\usepackage{subfigure}
```

Loads [`subfig`](/docs/reference/floats/subfig) under this name, so a document asking for either gets the same.

## Commands

`\subfigure`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="subfigure.tex" preview
\documentclass{article}
\usepackage{subfigure}
\begin{document}
\begin{figure}[h]\subfigure[A]{\rule{1cm}{1cm}}\subfigure[B]{\rule{1cm}{1cm}}\caption{Two}\end{figure}
\end{document}
```
