## Loading

```latex
\usepackage{caption}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\captionof`, `\captionsetup`, `\DeclareCaptionFont`, `\DeclareCaptionFormat`, `\DeclareCaptionLabelFormat`, `\DeclareCaptionLabelSeparator`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written:

```latex title="caption.tex"
\documentclass{article}
\usepackage[font=small,labelfont=bf]{caption}
\begin{document}
\captionsetup{font=small,labelfont=bf,labelsep=period}
\begin{figure}[htbp]
\centering
\rule{2cm}{1cm}
\caption[Short]{A long caption for a figure.}
\end{figure}
\captionof{table}{A caption outside a float.}
\end{document}
```
