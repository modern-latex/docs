## Loading

```latex
\usepackage{wrapfig2}
```

Loads [`wrapfig`](/docs/reference/floats/wrapfig) under this name, so a document asking for either gets the same.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="wrapfig2.tex" preview
\documentclass{article}
\usepackage{wrapfig2}
\begin{document}
\begin{wrapfigure}{r}{3cm}\rule{2cm}{1cm}\end{wrapfigure}Wrapped text.
\end{document}
```
