## Loading

```latex
\usepackage{algorithm}
```

A module of its own, compiled into mLaTeX: the package's commands are defined over mLaTeX's primitives.

## Commands

`\algorithmname`, `\floatname`, `\listalgorithmname`, `\listofalgorithms`, `\neq`.

## Example

A document that uses it, from mLaTeX's own tests, so it compiles as written, and below it what mLaTeX sets from it in your browser:

```latex title="algorithm.tex" preview
\documentclass{article}
\usepackage{algorithm}
\usepackage{algpseudocode}
\begin{document}
\begin{algorithm}[htbp]
\caption{Euclid's algorithm}\label{alg:euclid}
\begin{algorithmic}[1]
\Procedure{Euclid}{$a,b$}
\While{$b\neq 0$}
\State $t \gets b$
\State $b \gets a \bmod b$
\State $a \gets t$
\EndWhile
\State \Return $a$
\EndProcedure
\end{algorithmic}
\end{algorithm}
Algorithm~\ref{alg:euclid} is Euclid's.
\end{document}
```
