---
title: Comparison
description: How mLaTeX differs from other TeX programs, Typst and online editors.
---

mLaTeX keeps LaTeX's language and replaces what runs it. That puts it somewhere new: closer to pdfLaTeX than to Typst in what you write, and closer to Typst than to pdfLaTeX in how it runs.

## vs. pdfLaTeX, XeLaTeX and LuaLaTeX

These are the programs of a TeX distribution such as TeX Live or MiKTeX: TeX itself, with LaTeX's kernel and packages loaded as macros from thousands of files.

|                   | TeX programs                                                       | mLaTeX                                                                   |
| ----------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------ |
| Install           | A distribution of several gigabytes, or packages fetched as needed | One program and its fonts                                                |
| Runs per document | Two or three, plus BibTeX or Biber, plus makeindex                 | One                                                                      |
| Files left behind | `.aux`, `.log`, `.toc`, `.bbl`, `.out` and more                    | Only the PDF                                                             |
| Packages          | Any of the thousands on CTAN, as `.sty` files                      | 509 packages and 14 classes, compiled in; others fall back to a glossary |
| Speed             | Seconds for a paper                                                | Milliseconds for a paper                                                 |
| Shell commands    | Possible with `--shell-escape`                                     | Never                                                                    |
| Output            | The reference for how LaTeX looks                                  | Close to it, not identical                                               |

The trade is coverage for speed and simplicity. A TeX distribution reads every package ever written for it, exactly. mLaTeX reads the ones documents actually use, and sets them the way those packages set them, closely but not to the pixel.

## vs. Typst

Typst is a newer typesetting system with a language of its own and fast, incremental compilation. It is a good choice for new documents, but documents have to be written, or rewritten, in Typst's markup.

mLaTeX takes the other road: the language stays LaTeX, so existing papers, templates, journal classes and habits carry over. If your documents are already LaTeX, mLaTeX is the shorter step.

## vs. Overleaf

Overleaf is an online editor with collaboration, history and templates, running a TeX distribution on its servers. It is an editor and a service; mLaTeX is a typesetter.

The two answer different questions, and they can be combined: mLaTeX can run on a server, inside another program through its C or C++ library, or in a browser through its WebAssembly build, which is how a live-preview editor could typeset without a round trip to a server at all.

## vs. Tectonic

Tectonic is a self-contained TeX program based on XeTeX that downloads the packages a document needs and runs as many passes as it takes. It removes the work of managing a distribution, while still running TeX and its macro packages underneath.

mLaTeX goes one step further: there are no packages to download and no TeX underneath. That is where the speed comes from, and also why a package outside mLaTeX's list is approximated rather than run.

## When to use something else

### You need a package mLaTeX does not cover, set exactly

Use a TeX distribution. Check [Supported Packages](/docs/packages) first.

### You need output identical to pdfLaTeX's, down to the line breaks

Use pdfLaTeX. mLaTeX follows TeX's algorithms, but its fonts, metrics and many details are its own.

### Your document runs external programs

A document that runs programs through `\write18`, for example to generate figures, needs a TeX distribution. mLaTeX will never run them.
