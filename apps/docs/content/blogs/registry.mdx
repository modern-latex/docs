mLaTeX ships with the packages most documents use, built in. But LaTeX lives on its packages, and no engine can carry all of them. The next piece of mLaTeX is a registry: a place to publish packages, find them and install them.

## Why not just CTAN?

CTAN is the archive the TeX world is built on, and it isn't going anywhere. A registry for mLaTeX solves a different problem.

A TeX distribution installs a snapshot of thousands of packages at once, and updates them all together. When a package changes, every document that uses it changes too, sometimes years after it was written. Ask anyone who has reopened an old paper and found it no longer compiles.

The registry works the way npm and PyPI do for code. Each document names the packages it needs and their versions, and gets exactly those.

## Versions that stay put

A published version never changes. Fixing a mistake means publishing a new version, never rewriting an old one, so a document that sets today sets the same way in ten years. Publishers can deprecate a version to steer people away from it, and can withdraw one only shortly after publishing it.

## Publishing

Publishing will be one command:

```bash
mlatex publish
```

A package is a folder with its source and a small manifest giving its name, version, license and what it depends on. Every package carries an open-source license, so anyone who installs it may use it and share it. Names are first come, first served, and impersonating another package is against the [terms](/legal/terms).

## Installing

Documents will name their packages beside them, and the engine fetches what's missing the first time it sets the document, then keeps a copy so the next run works offline. The browser editor uses the same registry, so a project sets the same way in the browser and in a terminal.

## Writing packages today

You don't have to wait for the registry to write a package. mLaTeX already reads `.sty` files beside a document, and [Writing Packages](/docs/packages/writing) explains how they work. A package written today will publish unchanged once the registry opens.
